# siftq 新UI 仕様

## 目的

作業対象（GitHub、Discord、メール、LLMへの指示）がツールごとに散り、コンテキスト切替で気が散る問題を解く。
タスクを軸に、そのタスクのチャット・メモ・ブラウザを1画面に集約する。

参考元は PM Hub。ただし日時管理・タグ・プロジェクト・実行上限は参考元固有の都合であり、siftq には持ち込まない。

## スコープ

- プロトタイプはフロントのみ。状態は localStorage に保存する。
- 実 GitHub API、メール、Discord、実 LLM、任意サイトの埋め込み表示は対象外。
- マルチユーザー、モバイル最適化は対象外。
- 開発場所は `poc/`。現行 `src/` の SIFTQ には触らない。
- プロダクト名は `siftq` のまま。

## 動かし方

`poc/` を静的配信して開く。状態は localStorage に保存する。

```bash
cd poc
python3 -m http.server 8099
```

`http://127.0.0.1:8099/` を開く。初期状態に戻すときはブラウザの localStorage を削除する。

VS Code Remote などで開く場合は、ポート 8099 を転送してから `http://localhost:8099/` を開く。

## 画面

Hub 1画面。4領域。

| 領域 | 内容 |
| --- | --- |
| 左 | タスク一覧（仮タスク + グループ別） |
| 中央 | 選択タスクのチャット / メモ |
| 右 | 選択タスクのブラウザ |
| 下 | AI使用量（モック） |

左・中央・右の幅はドラッグで変更でき、再読み込み後も保持する。

## タスク

siftq 現行モデルを継承する。

- 状態は `do / done / skip`。初期表示は `do`。
- `done / skip` は状態切替タブで絞り込んで表示する。
- `working` は印のみ。実行上限は持たない。
- `project`（グループ名）を持つ。未設定は `その他` とする。
- `order` をデータとして持つ。追加と昇格・降格では一覧の先頭に置く。
- 追加はタイトルとグループを選ぶ。新規グループはセレクトの「+ 新しいグループ」から作る。日付・タグの構文は持たない。
- 左の丸は状態表示のみ。押しても何も起きない。状態変更は右クリックメニューから行う。
- グループ見出しは `▽` で開閉できる。閉じた状態は保存する。
- グループとタスクはDnDで並べ替えできる。
- タスクは同じグループ内の順序を変更でき、別グループへ移動できる。
- プロジェクトグループは見出しをドラッグして並べ替えできる。仮タスクは先頭固定とする。
- 仮タスクと通常タスクの間はDnDで移動しない。移動は右クリックメニューから行う。
- 仮タスクは現行 Idea の後継。`pinned` と `order` を持ち、一覧の先頭に置く。
- 仮タスクと通常タスクは相互に移動できる。移動は右クリックメニューから行う。
- 通常タスクの作成時に、空のチャットと空のメモを同時に作る。
- GitHub 通知由来のタスクは `source` 印と未読印を持つ。開くと未読が消える。
- タスクを右クリックするとステータス変更メニューを開く。`do / done / skip` を選ぶと状態が変わる。
- 右クリックメニューからグループを移動できる。新規グループもここから作れる。
- 仮タスクの右クリックメニューは「タスクに昇格」と「固定」の切替を表示する。

### 表示順

`do` の表示はグループごとに分ける。仮タスクは先頭固定、プロジェクトグループは保存された順に並ぶ。初期値はグループ名の昇順で `その他` を末尾とする。

- 仮タスク: 1セクションにまとめ、`pinned` を先に、各グループ内は `order` 昇順。
- 通常タスク: グループごとに `order` 昇順。
- `done / skip`: グループ分けせず `updated_at` 降順。

## チャット（中央）

チャットは siftq にない新しい概念で、タスクに紐づく LLM 会話とする。Task/Idea の description とは別に持つ。

- 1タスクに1会話を持つ。プロトタイプでは会話の追加UIを持たない。
- 送信は `Ctrl/Cmd+Enter`、改行は `Enter`。
- 送信中は Working（経過秒）と停止ボタンを表示する。
- アシスタント応答に「コピー」「タスクにする」を付ける。
- 「タスクにする」は応答内容から通常タスクを作る。
- モデル選択欄を持つ。プロトタイプでは表示のみ。
- 文脈はメモ全文と現在のブラウザ URL を含む前提とする。

## メモ（中央）

メモはタスクに紐づく LLM 共有メモ。1タスクに1枚。

- ユーザーと LLM の両方が編集する想定。
- 入力は自動保存する。
- チャットの文脈に常に含まれる。

## ブラウザ（右）

- タスクごとにタブ群を持つ。
- タブの追加・切替・URL 遷移は動く。
- ページ本体はモック表示とする。任意サイトの埋め込みは行わない。
- 現在の URL とタイトルをチャットの文脈として扱う。

## GitHub 連携

最初の外部連携は GitHub とする。

- 通知を受けると `source = github` のタスクを作る。
- 通知の URL をブラウザのタブに開く。
- 未読印を付ける。
- プロトタイプではシードデータに通知タスクを置く。

## 使用量

下部にセッションと週次の使用量バーを表示する。プロトタイプでは固定値。

## 認証

現行の認証は残す。`poc/` のプロトタイプはログインなしで開ける。

## データモデル（プロトタイプ）

localStorage に保存する。概念上は次のエンティティに分かれる。プロトタイプでは会話・メモ・ブラウザタブを Task の下に入れ子で持つ。

| エンティティ | 属性 |
| --- | --- |
| Task | id, kind（task / tentative）, title, project, status, working, pinned, unread, source, order, created_at, updated_at |
| Conversation | id, task_id, title, messages |
| Message | id, conversation_id, role（user / assistant / tool）, content, status |
| Memo | task_id, content, updated_at |
| BrowserTab | id, task_id, url, title, active |
| Usage | session, week |
| UI state | projectOrder, collapsed, paneWidths |

## 暫定実装

見た目と操作は本物、中身と永続化は偽物とする。

| 領域 | 暫定の実現 | 差し替え先 |
| --- | --- | --- |
| 永続化 | localStorage + シードデータ | D1 |
| LLM 応答 | 固定文の擬似ストリーミング | LLM API |
| GitHub 通知 | シードデータに通知タスクを置く | GitHub API |
| ブラウザ | URL バーとタブは本物、ページはモック | 別方式を検討 |
| 使用量 | 固定値 | 実計測 |

## 今後の統合

プロトタイプで UI を固めた後、`poc/` の画面で `src/` の Matrix / Tasks / Ideas を置き換える。その時点で既存の認証と D1 を接続する。

## 非スコープ

- 日時管理、タグ、プロジェクト、実行上限、Vice、借りタスク
- 実 LLM の応答品質とツール実行
- 外部サイトの完全な表示
- 認証の変更
