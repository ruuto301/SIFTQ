# siftq poc 仕様

## 目的

複数プロジェクトの作業対象を1画面に集約する。
タスク管理UIは `poc/` のプロトタイプを維持し、チャットとモデル選択の実体を DSH に任せる。

## スコープ

- 同一リポジトリの `poc/` に置くローカルWebアプリ。
- サーバは `127.0.0.1` にのみバインドする。
- DSH を `dsh --profile acp` で起動し、ACP で接続する。
- タスク、グループ、メモ、ブラウザタブ、会話メタ情報はJSONに保存する。
- 使用量表示、リモートアクセス、デスクトップアプリ化は対象外。
- ブラウザはモック表示のまま。実ブラウザ操作とGitHub連携は対象外。

## 動かし方

```bash
cd poc
bun install
bun run dev
```

`http://127.0.0.1:8099/` を開く。

- DSH のモデルを使う場合は `DEEPSEEK_API_KEY` を起動環境に設定する。
- DSH なしでUIとチャットを確認する場合は `POC_DSH=mock bun run dev` を使う。
- DSHのプロファイルは `acp`。`POC_DSH_PROFILE` で変更できる。
- DSHの実行ファイルは `POC_DSH_BIN` で変更できる。

## 画面

- 上部: `siftq`、DSH接続状態、設定ボタン。
- 左: タスク一覧。グループの折りたたみ、DnD、仮タスク、右クリック状態変更。
- 中央: チャット / メモ。
  - チャットバーにモデルselectと権限selectを並べる。
  - モデルselectはACPのconfig optionsから生成する。
  - 送信中は Working と停止ボタンを表示する。
  - アシスタント応答に「コピー」「タスクにする」を付ける。
- 右: ブラウザ（モック）。
- 設定: グループの追加・名前変更・削除、workspace設定、DSH接続状態、再接続。

## グループ

- `groups.json` にグループ名、workspace、並び順を持つ。
- workspaceは空でもよい。空の場合はアプリの起動ディレクトリでDSHを動かす。
- グループを削除し、タスクが残っている場合は「その他」へ移動する。
- `その他` は削除・名前変更できない。
- タスク作成欄の「+ 新しいグループ」でもグループを作成する。
- グループの並び順は左ペインのDnDで変更する。

## タスク

- 状態は `do / done / skip`。初期表示は `do`。
- `working` は印のみ。実行上限は持たない。
- 左の丸は状態表示のみ。押しても何も起きない。状態変更は右クリックメニューから行う。
- 仮タスクは通常タスクと相互に移動できる。移動は右クリックメニューから行う。
- タスクは同じグループ内で並べ替え、別グループへ移動できる。
- 仮タスクと通常タスクの間はDnDで移動しない。
- 通常タスクの作成時に、空の会話と空のメモを作る。

## チャットとメモ

- チャットはタスクに紐づくDSHセッション。
- メモはタスクに紐づく共有メモで、自動保存する。
- 文脈はメモ全文と現在のブラウザURLを前提とする。
- アシスタントの応答はACPの `session/update` を受けて表示する。
- 停止は `session/cancel`。
- 権限は会話ごとに「確認する / すべて許可」を持つ。
  - 確認する: 承認ダイアログを表示する。
  - すべて許可: その会話の承認要求を自動で許可する。
- モデルと reasoning effort はACPのconfig optionsから選択する。

## DSH接続

- 起動時に `dsh --profile acp` を起動し、`initialize` を試す。
- 接続に失敗してもアプリは動く。設定画面にエラーと再接続ボタンを表示する。
- 会話ごとに `session/new` し、セッションIDを保存する。
- 再起動後は `session/resume` を試す。再開できない場合は新しいセッションを作る。
- モデル変更は `session/set_config_option`。
- 承認は `session/request_permission` に応答する。
- `POC_DSH=mock` ではDSHを起動せず、固定応答を返す。

## 保存

- `poc/data/groups.json`: グループ名、workspace、並び順。
- `poc/data/state.json`: タスク、メモ、ブラウザタブ、会話メタ情報、画面設定。
- `poc/data/chats/<conversationId>.json`: チャット履歴のミラー。
- 書き込みは一時ファイルに書いてからrenameする。
- `poc/data/` はgit管理外。

## 既知の制約

- ACPは確定したメッセージ単位の更新になる。トークン単位のストリーミングではない。
- `DEEPSEEK_API_KEY` がない場合、DSHのモデル呼び出しは失敗し、画面にエラーを表示する。
- セッションを再開できない場合は、履歴表示は残るがDSH側の文脈は新しくなる。
- ブラウザはモック表示で、外部ページ本文は取得しない。

## 非スコープ

- 使用量表示
- リモートアクセス
- デスクトップアプリ化
- 実ブラウザ操作
- スレッド表示
- GitHub連携の実装
