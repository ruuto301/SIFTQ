# ADR 0078: メモ機能を Ideas に一本化する

## 決定

- 旧 Ideas（カード一覧とタスク化）を削除し、DB の ideas テーブルと domain を廃止する。
- MK のメモ機能を Ideas の名前・URL・内部名へ移す。画面は Ideas、URL は /ideas、API は /api/ideas/notes とする。
- テーブルは mk_notes を ideas、mk_images を idea_images に rename する。旧 Ideas のデータは取り込み済みのため DROP する。
- 旧 URL と旧 API の互換は残さない。
- 画面内の文言（メモ、アーカイブ、ゴミ箱）は変更しない。

### 決定の理由

- 似たメモ機能が 2 つ並存すると、保存先と導線の判断を迷わせる。
- タスク化は Tasks 側の導線で足り、旧 Ideas の役割は残っていない。
- 内部名を Ideas に揃えると、画面・API・テーブルの対応が読みやすくなる。

### 代替案

- 旧 Ideas を残して MK の名前だけを維持する案は、重複が解消しないため却下した。
- 旧 URL をリダイレクトで残す案は、互換のために古い経路を維持する必要があり却下した。

### 影響

- 旧 Ideas のデータは復元できない（事前に取り込み済みであることを前提とする）。
- 旧 URL と旧 API を参照する利用者は 404 になる。
- MCP の Ideas ツールは削除し、メモ操作用の MCP ツールは提供しない。
